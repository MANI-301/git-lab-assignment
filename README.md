
## Getting Started

1. **Clone the repo**: `git clone https://github.com`
2. **Create a branch**: `git checkout -b feature`
3. **Commit changes**: `git commit -m "Add helpful message"`
4. **Push to GitHub**: `git push origin feature`

Instructions:(Refer Task-Screenshots Folders fro Answers)

* Perform all tasks on your local machine.
* Create a GitHub account if you do not already have one.
* Submit screenshots and command history as proof of completion.
* Create a single repository and complete all tasks within it 

Git Basics (Local Repository)**

1. Install Git on your system and verify installation using the appropriate command.

2. Configure your Git username and email globally.

3. Create a new folder named `git-lab-assignment` and initialize it as a Git repository.

4. Create a file named `README.md` and add a short project description.

5. Check the repository status.

6. Add the file to the staging area and commit it with the message:
   `"Initial commit"`

7. Create a new file named `index.html` and add basic HTML structure.

8. Stage and commit the new file with an appropriate message.

9. View the commit history using a Git log command.

10. Modify `README.md`, add new content, and check the difference before committing.

Working with GitHub (Remote Repository)**

16. Create a new public repository on GitHub named `git-lab-assignment`.

17. Connect your local repository to the GitHub repository (add remote origin).

18. Push your local repository to GitHub.

19. Make a change directly in GitHub (edit README.md online), then pull the changes to your local repository.

20. Create a new branch locally, push it to GitHub, and create a Pull Request. Merge the Pull Request on GitHub.
