Project Version Control


Git:
 A distributed version control system used to track changes in the source code during software development. It allows for rapid branching, easy merging, and the ability to revert to previous project states.


GitHub:
 A web-based hosting service for Git repositories. It provides a collaborative interface for version control, including features like pull requests, issue tracking, and automated workflows (CI/CD).


## Getting Started

1. **Clone the repo**: `git clone https://github.com`
2. **Create a branch**: `git checkout -b feature-name`
3. **Commit changes**: `git commit -m "Add helpful message"`
4. **Push to GitHub**: `git push origin feature-name`
